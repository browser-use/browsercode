Starts or resumes one stronger BrowserCode subagent. The expert receives the
original requirements, current browser state, recent failures, and current
draft instead of a copied transcript. It shares the exact live CDP session and
workspace, can act directly, and returns a compact receipt with fresh state.

Use it only when you cannot reliably continue after inspecting fresh state and
trying the obvious recovery: the required strategy remains unclear, an
important source/record decision is ambiguous, progress is genuinely stalled,
or a required claim cannot be supported. A single navigation timeout is not a
blocker when the page is usable or retrying/inspecting state is straightforward.

Obvious clicks, typing, scrolling, and already-clear browser sequences do not
need an early handoff. The harness automatically runs one expert audit when you
first try to finish, so do not call this tool merely for a final check.

The `request` must name only the immediate blocker or decision. Never ask the
expert to complete the remaining task, extraction, or artifact; the expert will
make the smallest sufficient intervention and return control. Later calls
resume the same expert session.
