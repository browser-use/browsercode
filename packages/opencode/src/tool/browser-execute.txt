Executes JavaScript in a browser via CDP.

Usage:
- Use this tool whenever the task requires driving a real browser.
- Use this tool to read webpages that block the webfetch tool.
- IMPORTANT: you MUST use the skill tool first to load the `browser-execute` skill. This tool will fail if you did not read those directions first.
- Return only the fields needed for the current decision. Large output is saved automatically; inspect that file with focused Grep/Read calls instead of loading it whole.
- After three tool calls that add no new evidence toward the same missing fact, stop repeating that strategy: change source or approach, report the limitation, or finish.
- Returns console output from the snippet; screenshots taken attach automatically as images.
